Rule, fixed before each run: publish a positive headline only if at least one `swap`
survives hand-verification and confirmed swaps outweigh false positives 2:1. Otherwise
the negative result is the result.

Repo names are deliberately excluded from these reports. The label map
(`R1..Rn → owner/name`) is written to `$TMPDIR/baseline-bench/labels.json` and not committed:
publishing an unfavourable verdict about someone else's dependency choices is not a trade
worth making for a tool announcement.
