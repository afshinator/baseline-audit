# Benchmark: 4 public web apps

Run 2026-10-29 with `node scripts/benchmark.mjs`. Repos are labelled, not named: this is an aggregate result, and naming other people's projects to advertise a tool is not a trade worth making. The label map stays local (`$TMPDIR/baseline-bench/labels.json`).

## Setup

- 4 repositories: 3 with a declared browserslist target set, 0 with none (audited against assumed Baseline-Widely targets), 1 with no production dependencies at all.
- 1 produced no mapped dependency at all; included deliberately so the sample is not all winners.
- 432 production dependencies scanned in total; 22 matched a row in the mapping table.

## Result

- **No package came back `swap`.** Every mapped dependency either needs a feature the project targets do not support, uses API surface the platform lacks, or has no usage analysis here.
- 9 `check`, 13 `blocked`/`blocked-cost`, 0 `keep`.
- 0KB recoverable from clean swaps in this sample.
- 7 verdicts changed when the same repos were re-audited against Baseline-Widely instead of their own targets.

## What the numbers do not say

- A `swap` verdict is a hypothesis, not a migration. Every swap in this run was checked by hand against the source (see the verification notes in the commit that added this file); false positives are reported there.
- Published package size is not tree-shaken size. Treat the KB figure as an upper bound.
- Four repos is a sample, not a survey. One of them exists to prove the tool can return nothing.
